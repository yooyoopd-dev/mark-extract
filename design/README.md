# 디자인 원본 (시각적 계약)

이 폴더는 Mark Extract UI의 **시각적 계약(visual contract)** 이다. 구현이 이 파일들과 어긋나면 구현이 틀린 것이다.

| 파일 | 내용 |
|---|---|
| `index.html` | 단일 화면 프로토타입 2,513줄. 디자인 토큰·레이아웃·컴포넌트·인터랙션의 원본 |
| `DESIGN-HANDOFF.md` | 구현 지침 (OpenDesign 생성) |
| `DESIGN-MANIFEST.json` | 화면·토큰·인터랙션·뷰포트 매트릭스의 기계 판독용 맵 |

## 포함하지 않은 파일

원본 압축 파일에는 `ref-tolaria.png`(2.2MB)가 있다. Tolaria라는 별개 앱의 스크린샷으로, `index.html`이 참고한 레이아웃 레퍼런스다. 저장소 용량 대비 실익이 없어 제외했다. 필요하면 원본 압축 파일에서 꺼내 쓴다.

## 디자인 대비 변경점

구현에서 원본과 달라지는 부분은 3건이며, 근거는 [`../docs/design/04-ui-spec.md`](../docs/design/04-ui-spec.md#디자인-대비-변경점)에 있다.

1. 뷰어 3번째 탭 '추출 필드' → **'변환 로그'**
2. 인스펙터 옵션 개편 (엔진 선택 추가, 청크 크기 제거, OCR 조건부 활성)
3. 설정 화면 신규 추가 (원본에 없음)

그 외 토큰·레이아웃·상태는 원본을 그대로 따른다.
